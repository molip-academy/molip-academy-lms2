# 16: 몰입일지 삭제 UI

**What to build:** 회원이 화면에서 잘못 쓴 날짜의 몰입일지를 지운다. 지운 뒤 같은 날짜에 다시 쓸 수 있다.

지우면 되돌릴 수 없으므로 실수로 눌리지 않아야 한다.

**Blocked by:** 15, 09

**Status:** ready-for-agent

- [ ] 일지가 있는 날짜에서 삭제할 수 있고, 일지가 없는 날짜에서는 삭제 수단이 보이지 않는다
- [ ] 삭제 전에 확인을 거친다
- [ ] 삭제 후 폼이 비고, 삭제됐음이 화면에 드러난다
- [ ] **삭제한 날짜에 곧바로 다시 저장이 된다**
- [ ] 브라우저에서 실제로 삭제되고, 다시 조회해도 나오지 않는다
