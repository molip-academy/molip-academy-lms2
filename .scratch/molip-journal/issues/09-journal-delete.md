# 09: 몰입일지 삭제

**What to build:** 회원이 잘못 쓴 날짜의 몰입일지를 지운다. 지운 뒤 같은 날짜에 다시 쓸 수 있어야 한다.

삭제는 **하드 삭제**다. 소프트 삭제는 `(회원, 일지 날짜)` unique 제약과 충돌해서, 지운 날짜에 새 일지를 못 쓰게 만든다.

**Blocked by:** 07

**Status:** done

- [x] 날짜로 지목하는 삭제가 그 날짜의 일지를 지운다
- [x] 지워진 일지는 조회되지 않는다
- [x] **지운 날짜에 다시 저장이 된다**
- [x] 일지가 없는 날짜를 삭제해도 서버가 깨지지 않는다
- [x] 회원 A가 회원 B의 일지를 지울 수 없다
- [x] 인증되지 않은 요청은 막힌다
- [x] 통합 테스트가 삭제, **삭제 후 재작성**, 남의 일지 삭제 차단을 덮는다
