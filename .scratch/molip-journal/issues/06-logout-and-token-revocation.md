# 06: 로그아웃과 토큰 폐기

**What to build:** 회원이 로그아웃하면 실제로 로그아웃된다. 공용 컴퓨터에서 자기 기록을 보호할 수 있어야 하므로, 이전 쿠키를 손에 넣은 사람이 다시 들어올 수 없어야 한다.

리프레시 토큰을 DB에 저장한 이유가 바로 이 티켓이다. 저장하지 않았다면 로그아웃은 쿠키를 지우는 시늉에 그친다.

**Blocked by:** 05

**Status:** done

- [x] 로그아웃 시 해당 리프레시 토큰이 DB에서 폐기된다
- [x] **로그아웃 전에 확보한 리프레시 쿠키로는 재발급되지 않는다** — 쿠키 삭제에만 의존하지 않는다
