# 04: 내 정보 조회

**What to build:** 로그인한 회원이 자기 아이디·닉네임·가입일을 확인한다. 어떤 계정으로 쓰고 있는지 알기 위해서다.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 내 정보 엔드포인트가 인증된 회원의 아이디·닉네임·가입일을 돌려준다
- [ ] 응답에 비밀번호 해시가 들어가지 않는다
- [ ] 인증되지 않은 요청은 막힌다
- [ ] 어느 회원의 정보를 줄지는 전적으로 인증 정보에서 나온다 — 요청이 다른 회원을 지목할 수 없다
- [ ] 통합 테스트가 인증된 조회와 미인증 차단을 덮는다
