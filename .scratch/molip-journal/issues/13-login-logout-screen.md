# 13: 로그인·로그아웃 화면

**What to build:** 회원이 브라우저에서 로그인하고 로그아웃한다. 새로고침해도 로그인이 유지되고, 일지를 쓰는 중에 액세스 토큰이 만료돼도 화면이 끊기지 않는다.

프론트에는 토큰을 보관하거나 헤더에 붙이는 코드가 없다. 인증은 전적으로 httpOnly 쿠키로 이뤄지므로 화면은 "로그인했는지 여부"만 안다.

- [x] 로그인 후 보호된 화면에 접근된다
