# 08: 몰입일지 입력값 검증

**What to build:** 말이 안 되는 값은 저장되지 않는다. 나중에 기록을 되짚거나 집계할 때 이상한 값에 걸리지 않기 위해서다. 반대로 **부분 작성은 정상으로 취급한다** — 기억나지 않거나 해당 없는 항목이 있는 게 당연하기 때문이다.

`슬로싱킹`·`1초원칙 준수`·`선잠`은 회원이 스스로 판단해 적는 값이다. 서비스는 이 값들을 계산하거나 사실 여부를 따지지 않고, 범위만 본다.
