## 티켓 이후에 추가된 것

아래는 이 16개 티켓에 **없던** 작업이다. 티켓 본문만 읽으면 현재 코드와 어긋나 보이므로 여기 적어 둔다.

| 작업 | 내용 |
|---|---|
| **Swagger UI** | springdoc 3.1.0. `dev`·`test`에서만 켜지고 실서버에서는 꺼진다(fail-closed) |
| **월별 목록 화면** | `GET /api/v1/journals?from=&to=` 추가. `/`가 목록, `/journals/:date`가 상세 겸 수정이 됨 ([ADR 0002](../../../docs/adr/0002-date-as-journal-resource-key.md)가 예고한 경로) |
| **실서버 배포** | Cloudflare Pages + Railway. H2 → Postgres + Flyway 전환, `ddl-auto: validate` |
| **공통 헤더** | 좌상단 브랜드가 목록으로, 닉네임이 내 정보로 |
| **로딩 경합 수정** | 스켈레톤 + 요청 순번으로 값 깜빡임·응답 뒤엉킴 제거 |

## 티켓과 현재 코드가 다른 지점

- **10번**: 티켓에는 프로파일 조건이 없지만, 실서버에 비밀번호가 알려진 샘플 계정이 생기는 것을 막기 위해 `@Profile("dev")`로 좁혔다. 티켓의 인수 조건은 개발 모드에서 그대로 성립한다.
- **15번**: 티켓은 날짜 선택기가 있는 단일 화면을 기술한다. 지금은 날짜가 URL에 있고 선택기는 이동 수단이 됐다.
- **15번의 시각적 기준이 된 화면 이미지가 저장소에 없다.** 대화에만 있었다.
