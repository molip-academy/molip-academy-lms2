# 05: 액세스 토큰 재발급

**What to build:** 회원이 일지를 쓰는 중에 액세스 토큰이 만료돼도 작업이 끊기지 않는다. 리프레시 쿠키로 새 액세스 토큰이 발급된다. 브라우저를 새로고침해도 로그인 상태가 유지되는 근거가 이것이다.

리프레시 토큰은 **DB에 저장한다.** 이 때문에 JWT의 무상태 이점은 액세스 토큰 검증에만 남는데, 폐기 가능성과 맞바꾼 의도된 선택이다 (ADR 0001).

**Blocked by:** 03

**Status:** done

- [x] 발급된 리프레시 토큰이 DB에 저장된다
- [x] 재발급 엔드포인트가 유효한 리프레시 쿠키를 받아 새 액세스 쿠키를 내린다
